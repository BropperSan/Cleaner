# 🧹 Cleaner

**Cleaner** is a VR game prototype focused on immersive interaction and haptic feedback.

The player controls a cleaning vehicle while exploring the environment and completing cleaning tasks. During gameplay, the player can encounter a hostile monster, adding tension and danger to the cleaning process.

## 🎮 Features

* VR gameplay
* Cleaning vehicle movement
* Interactive cleaning mechanics
* Enemy monster encounters
* Immersive environment
* Haptic feedback system

## 🥽 Haptic Feedback

The project supports body feedback through compatible haptic devices, including:

* Haptic vest
* Haptic gloves
* Other body feedback devices

The feedback is used to make collisions, attacks and interactions feel more immersive.

## 🛠️ Technologies

* Unity
* C#
* VR / XR
* Haptic device integration

## 🔄 Gameplay

Explore the area → clean the environment → avoid the monster → complete cleaning objectives.

## 📌 Status

**Prototype completed.**

The main movement, cleaning, enemy and haptic feedback systems have been implemented.
